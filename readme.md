# Механик машин (Machine Mechanic)

Расширение для **SillyTavern** — форк Memory Books. Иконка-ключ 🔧 рядом с
волшебной палочкой открывает полный интерфейс приложения **прямо в чате как
сообщение**, целиком на русском. Работает **без** отдельной Memory Books.

## Возможности
- **🔧 интерфейс в чате** — значок у палочки рисует настоящий интерфейс приложения
  как сообщение в ленте; крестик / «Закрыть» убирают.
- **Русский принудительно** — независимо от языка SillyTavern.
- **«?» контекстная справка** — у каждой настройки; клик открывает справку на нужном
  месте с подсветкой.
- **Маркеры сцены ◄►** — в видимой шапке каждого сообщения (не в скрытом меню),
  удобно на телефоне.
- **🌐 Перевод сообщений** — значок у сообщения переводит его через ИИ (перевод под
  сообщением). Свой промпт, профиль подключения SillyTavern, своя температура.
- **🎲 Кубик** — свой рандомайзер; режимы «число» / «успех-провал» (у каждого свой
  промпт); разовый форс следующего броска; шкала критичности. Вкл/выкл значком 🎲
  у кнопки «Отправить» или галочкой в панели. **Бросок ИИ** скрыто уходит в промпт
  (по умолчанию не показывается — опция «Не показывать бросок ИИ»), **бросок
  пользователя** («Бросить сейчас») виден всегда.
- **🧠 Дневник души** — «живая» память на каждый чат в `.md` (дневник/эмоции/
  отношения/факты), модель пишет её сама. Перед авто-обновлением спрашивает
  «Обновить дневник души? Да/Нет». Требует серверный плагин `soul-md`.
- **🎯 Цели (Objective)** — встроенный порт расширения Objective. Значок 🎯 у поля
  ввода открывает панель: впиши цель — ИИ разобьёт её на список задач и незаметно
  ведёт к ним по ходу ролеплея, периодически проверяя выполнение. Авто-генерация
  задач, ветвление на подзадачи, кастомные промпты, слэш `/taskcheck`, встроенная
  инструкция «Как пользоваться». Данные общие со стандартным Objective
  (`chat_metadata.objective`) — старые цели подхватываются. Отдельное расширение
  Objective лучше **выключить**, чтобы не было двойной проверки.
- **🎬 Режиссёр (Director)** — скрытый «мастер сцены» внутри панели 🎯 (тумблер 🎬 в
  шапке + кнопка «Режиссёр ▸»). Раз в N ответов фоновой моделью смотрит на разговор,
  обновляет «мир» чата (локация, время, инвентарь, статусы, факты, NPC — файл
  `World.md` на сервере `soul-md`, удаляется вместе с чатом) и по ритму вбрасывает
  событие (encounter / discovery / visitor / twist / romance / none), которое персонаж
  сам вплетает в ответ (в т.ч. вводит NPC). Событие показывается всплывашкой и цветной
  плашкой под сообщением (переживает перезаход, в лорбук и контекст модели не пишется),
  у плашки — кнопка 🌐 перевода. Учитывает активную Цель (Objective). Промпты — на
  английском (как весь плагин), каждый тип события редактируется отдельно; интерфейс —
  русский, любой промпт можно прочитать по кнопке 🌐. Дневник души 🧠 и режиссёр 🎬
  делят общую очередь — одновременно к модели не ходят. Требует серверный плагин
  `soul-md` (как и 🧠).
    - **Типы событий:** encounter / discovery / visitor / twist / romance / **advancement
      («Продвижение»** — двигает сюжет под конкретного персонажа: в промпт режиссёра
      подмешана карточка) / none, плюс **custom («Своё»)** — пустой промпт, вписываешь
      сам, само не вылезает, только кнопкой.
    - **Пресеты ритма:** «Сбалансированный» / «Порезче». **Кнопки «Стригерить событие»** —
      разово гарантированно выдать выбранный тип на текущем пресете.
    - **Показ события:** «Настоящее событие» (сразу, в сообщении) / «Анонс» (плашка-анонс
      сейчас, событие — следующей генерацией). **Тумблер «Жёсткая директива»** (по умолч.
      выкл) — заставлять модель отыгрывать. **Свой лимит токенов** на ответ режиссёра.
    - **Свайп-фикс:** перегенерация ⟲ стрелками сохраняет событие (переписывает тот же),
      новое сообщение — расходует.
- **Стрелки ◄► у ножниц** — расширяют выделение текста для «Clip» на соседние сообщения.

## Установка (по ссылке)
В SillyTavern: **Extensions → Install extension** → вставить URL этого репозитория → **F5**.
Обновление — кнопка **Update** у расширения.

Кнопки 🔧🎲🧠🎯 появятся внизу, у поля ввода, рядом с волшебной палочкой.

## Разработка / сборка
```
npm install
npm run build   # esbuild: index.js + style.css -> index.build.js + style.build.css
```
`machineMechanic.js` и `help.html` грузятся напрямую — их правки видны сразу (F5),
без пересборки. Пересборка нужна только после правок `index.js` / `style.css`.
